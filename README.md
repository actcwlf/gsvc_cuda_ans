# ANSCoder for GSVC
Entropy Coder used in **An Exploration with Entropy Constrained 3D Gaussians for 2D Video Compression**
## Installation
Clone the project
```bash
git clone https://github.com/actcwlf/gsvc_cuda_ans.git
```

Install the project
```bash
python setup.py install
```
